📚 공부요정 - 초등 학습앱

초등학교 3~6학년 학생이 집에서 스스로 학습할 수 있는 웹 기반 학습 게임 앱입니다.
로그인 없이 개별 프로필을 등록해서 사용하며, 수학·국어·영어 3과목과 구구단·끝말잇기 게임을 즐길 수 있습니다.

**🔗 바로 사용해보기: [https://windhak.github.io/study-app/](https://windhak.github.io/study-app/)**

## ✨ 주요 기능

- **프로필 관리**: 로그인 없이 학교/학년/반/번/이름/프로필명으로 프로필 등록, 여러 명이 함께 사용 가능
- **프로필 사진**: 프로필 생성 시 사진을 첨부하면 프로필 목록과 홈 화면에 표시, 언제든 사진 변경 가능 (기기 내 자동 리사이즈 후 저장)
- **자동 로그인**: 마지막으로 사용한 프로필로 자동 진입, 언제든 다른 프로필로 전환 가능
- **7가지 학습 콘텐츠**
  - ➕ **수학**: 덧셈·뺄셈·곱셈·나눗셈 (난이도 1~5단계, 자릿수와 연산 종류가 단계적으로 어려워짐)
  - 🔤 **국어 낱말 게임**: 초성 힌트를 보고 낱말 맞히기 (띄어쓰기가 달라도 정답으로 인정)
  - 📝 **국어 문장 연습**: 1~2단계는 문장 빈칸 채우기, 3~5단계는 생활 속 상황에 맞는 행동을 고르는 객관식 (친구 관계·안전 등)
  - 🔠 **영어 단어**: 영어 단어를 보고 4지선다로 뜻 맞히기, 🔊 버튼으로 발음 듣기 지원 (브라우저 내장 음성, 서버 불필요). **학년제 10단계(초1~고3)·총 1,000낱말** 내장
  - 📖 **영어 문장**: 학년제 10단계(초1~고3). 1~5단계는 문장 빈칸에 알맞은 단어 고르기, 6~10단계는 영어 문장의 뜻 고르기 (총 200문항, 🔊 문장 듣기 지원)
  - 🎮 **구구단 게임**: 2~9단 범위의 곱셈·나눗셈 문제
  - 🔗 **끝말잇기**: 12개 주제(동물·음식·학교·자연·생활용품·나라·몸·운동·과학·직업·날씨·자유) 중 하나를 골라 요정이와 번갈아 낱말을 이어가는 게임. 낱말 10,000개 내장, 두음법칙 허용, 한 게임 안 중복 금지. **아이가 낸 낱말은 사전에 없어도 끝말만 이어지면 인정**
- **학습 설정**: 시작 전 "학습 시간(분)" 또는 "문제 수" 중 선택해서 진행 (끝말잇기는 목표 없는 무한 모드)
- **문제당 제한시간 1분**: 끝말잇기를 뺀 모든 문제는 1분 제한이 있고, 화면 상단에 **크고 눈에 띄는 카운트다운**이 표시됩니다(10초 이하로 남으면 빨간색으로 강조·깜박임). 1분이 지나면 오답 처리 후 다음 문제로 넘어가며, 다음 문제로 넘어가기 전 **정답을 3초간** 보여 줍니다
- **새 버전 자동 감지**: 새로 배포되면 앱을 열거나 다시 돌아왔을 때 "✨ 새 버전이 나왔어요!" 배너로 알려 줍니다(게임 중에는 방해하지 않음). 배너의 "지금 받기" 버튼을 누르거나, 다음 퀴즈를 시작할 때 자동으로 최신 버전이 적용됩니다 — 직접 새로고침하지 않아도 됩니다
- **학습 기록**: 프로필별로 정답률, 문제 수, 스티커 보상 등을 기록하고 확인 가능
- **스티커 보상**: 세션 정답률 70% 이상 시 스티커 지급으로 학습 동기 부여 (끝말잇기는 점수 100/200/350점 기준)
- **요정이 챗봇**: 규칙 기반(실제 AI 아님) 마스코트 챗봇으로, 인사·격려·과목 추천은 물론 가면라이더·파워레인저·로블록스 같은 아이들 관심사 잡담도 정해진 안전한 범위 안에서 가능

## 🛠️ 기술 스택

프레임워크 없는 **순수 HTML/CSS/JavaScript**로 제작되었습니다.

| 영역 | 선택 | 이유 |
|---|---|---|
| 마크업/스타일 | HTML5 + CSS3 (Flexbox) | 빌드 과정 없이 파일만 열어도 동작, 구형 브라우저 호환성 확보 |
| 로직 | Vanilla JavaScript | 구형 스마트폰 브라우저(저사양 WebView 등)에서도 안정적으로 동작 |
| 데이터 저장 | 브라우저 `localStorage` | 서버 없이 기기별로 프로필과 학습 기록 저장, 오프라인 사용 가능 |

구형 갤럭시 스마트폰처럼 오래된 기기의 브라우저에서도 문제없이 동작하도록 설계했습니다.

## 📁 프로젝트 구조

```
study-app/
├── index.html   # 화면 구조 (프로필 선택 · 홈 · 요정이 · 끝말잇기 3화면 · 난이도 · 설정 · 퀴즈 · 결과 · 기록, 총 11개 화면)
├── style.css    # 스타일 (아이 친화적 컬러 시스템, 반응형 모바일 우선 레이아웃)
├── data.js      # 콘텐츠 데이터 뱅크(국어/영어 단어, 국어·영어 문장·상황) + 문제 생성기(수학/구구단) + 요정이 챗봇 응답 데이터
├── data-wordchain.js  # 끝말잇기 사전 (10,000낱말 2티어 구조, 끝말잇기 첫 진입 시 인덱스 생성)
```

## 🚀 로컬에서 실행하기

빌드 과정이 필요 없습니다. 저장소를 내려받아 `index.html`을 브라우저로 열기만 하면 됩니다.

```bash
git clone https://github.com/windhak/study-app.git
cd study-app
# index.html을 브라우저로 열기
```

또는 간단한 로컬 서버로 실행할 수도 있습니다.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

## 💾 데이터 저장 방식

별도의 서버나 데이터베이스 없이, 브라우저의 `localStorage`에 아래 정보를 기기별로 저장합니다.

- `studyapp_profiles`: 등록된 프로필 목록 (사진을 첨부한 경우, 리사이즈된 이미지가 `photo` 필드에 base64로 함께 저장됨)
- `studyapp_lastProfileId`: 마지막으로 사용한 프로필 (자동 진입용)
- `studyapp_records_{프로필ID}`: 프로필별 학습 세션 기록 (최근 100건)
- `studyapp_stickers_{프로필ID}`: 프로필별 누적 스티커 개수
- `studyapp_wcbest_{프로필ID}`: 끝말잇기 주제별 최고 기록 (낱말 수 / 점수)

⚠️ 데이터는 사용하는 기기와 브라우저에 저장되므로, 다른 기기에서는 학습 기록이 공유되지 않습니다.

## 🧚 요정이 챗봇에 대해

홈 화면의 "요정이와 대화하기"는 **실제 생성형 AI가 아니라, 미리 정해둔 키워드-응답 규칙으로만 동작하는 스크립트 챗봇**입니다.

- 서버나 외부 API 호출이 전혀 없고, 모든 응답은 앱 안에 내장된 문구 중에서만 선택됩니다.
- 대화 내용은 어디에도 전송/저장되지 않으며, 화면을 나가면 사라집니다.
- 인사·격려·과목 추천처럼 정해진 안전한 주제 범위 안에서만 반응하도록 설계했습니다.
- 가면라이더·파워레인저·로블록스 등 아이들이 좋아하는 콘텐츠에 대한 가벼운 잡담도 가능하지만, 실시간 인터넷 검색이 아니라 미리 조사해서 넣어둔 고정 정보이며 저작권 보호를 위해 일반적인 팬 대화 수준으로만 구성했습니다.
- 범위를 벗어난 입력에는 "선생님이나 부모님과 이야기해보라"는 식으로 안전하게 안내합니다.

## 🔗 끝말잇기 규칙

- **주제 12개**: 주제를 골라도 아무 낱말이나 낼 수 있고, 주제에 맞는 낱말이면 **보너스 +5점**을 받습니다. "자유"는 사전 전체를 씁니다.
- **두음법칙 허용**: `달력 → 역사`, `정리 → 이슬` 처럼 두음이 바뀌는 연결을 양방향으로 인정합니다.
- **중복 금지**: 한 게임 안에서 이미 나온 낱말은 다시 쓸 수 없습니다.
- **사전에 없는 낱말도 인정**: 아이가 낸 낱말은 사전에 없어도 **끝말이 이어지고 · 한글 두 글자 이상이고 · 중복이 아니면** 그대로 인정합니다. 요정이는 뜻을 모른다고 솔직히 말한 뒤 그래도 이어가겠다고 답하고 다음 낱말을 냅니다.

  > 아이: 교실뽀짝
  > 요정이: "교실뽀짝"은 요정이가 아직 못 배운 낱말이야. 뜻은 모르지만 그냥 이어갈게!
  > 요정이: 그럼 나는 "짝수"!

  내장 사전이 아이가 아는 낱말을 다 담을 수는 없으므로, 틀렸다고 막지 않는 쪽을 택했습니다. 사전에 없는 낱말은 주제 보너스 대상이 아닙니다.
- **거부되는 경우는 세 가지뿐**: 끝말이 안 이어짐 / 한 글자 이하이거나 한글이 아님 / 이미 나온 낱말. 어느 경우도 감점이나 패배가 아니고, 타이머를 유지한 채 다시 입력받습니다.
- **한 턴 60초 · 무한 모드**: 목표 없이 계속 이어가며, 60초를 넘기거나 "모르겠어요"를 누르면 끝납니다.
- **요정이를 막으면 라운드 승리**: 요정이가 이을 낱말을 못 찾으면 **+30점**을 받고 새 낱말로 다음 라운드가 이어집니다.
- **요정이의 낱말 선택 순서**: ① 이을 수 없는 낱말(한방단어)은 절대 쓰지 않음 → ② 80%는 잇기 쉬운 낱말·20%는 조금 생각해야 하는 낱말 → ③ 초등 어휘 우선 → ④ 2~3글자 우선. 실제로 요정이가 내는 낱말의 **86%가 초등 어휘**이고 4글자 이상은 1%입니다.
- **사전 2티어 구조**: 요정이는 **Tier 1(6,921낱말 · 초등~중급)**에서 먼저 고르고, 이을 낱말이 없을 때만 **Tier 2(3,079낱말 · 확장 어휘)**로 내려갑니다. Tier 2가 쓰이는 비율은 약 3%입니다.
- **점수**: `이어간 낱말 × 10점 + 주제 보너스 × 5점 + 라운드 승리 × 30점`

## 📖 끝말잇기 사전 출처 및 라이선스

끝말잇기 사전(`data-wordchain.js`)의 낱말 데이터는 **국립국어원 「한국어기초사전」**(한국어 학습자용 사전)에서 가져와 가공한 것입니다.

- 원자료: <https://krdict.korean.go.kr> — [spellcheck-ko/korean-dict-nikl](https://github.com/spellcheck-ko/korean-dict-nikl) 배포본 사용
- 원저작자: 국립국어원 (National Institute of Korean Language)
- 라이선스: 원자료 CC BY-SA 2.0 KR → **이 파일의 낱말 데이터는 CC BY-SA 4.0** 을 따릅니다
- 가공 내용: 명사 표제어 추출 → 어휘등급(초급·중급·고급)으로 계층 분리 → 의미범주로 12개 주제 자동 태깅 → 아동 부적합 낱말 제거

낱말 데이터는 이 한 파일에만 담겨 있으며, 앱의 나머지 코드와는 분리되어 있습니다.

### 아동 부적합 낱말 처리

일반 국어사전에는 범죄·성·질병·비하 표현이 당연히 포함되어 있고, 요정이가 그런 낱말을 아이에게 말하면 안 됩니다. 두 겹으로 걸러냈습니다.

1. **의미범주 단위 배제** — `정치와 행정 > 사법 및 치안 행위`(범죄 행위), `인간 > 생리 현상`, `삶 > 병과 증상`, `종교` 범주를 통째로 제외
2. **낱말 차단 목록** — 범주 필터를 빠져나가는 낱말 약 200개를 개별 차단

Tier 2(확장 어휘)는 위 필터를 통과한 **안전 의미범주**(동식물·식생활·자연·교육·스포츠·과학·주생활·의생활·문화·신체 부위·시간·교통·직업 등)에서만 뽑았습니다.

## ✍️ 화면 문구 맞춤법 검수

앱에 표시되는 모든 문구를 **국립국어원 자료 기반 hunspell 한국어 맞춤법 사전**([spellcheck-ko/hunspell-dict-ko](https://github.com/spellcheck-ko/hunspell-dict-ko))으로 검사하고 정정했습니다.

| 구분 | 수정 전 | 수정 후 |
|---|---|---|
| 오타 | 모르겜어요 | 모르겠어요 |
| 이중 피동 | 앱에서 보여질 별명 | 앱에서 보일 별명 |
| 대명사 | 나도 너가 최고라고 | 나도 네가 최고라고 |
| 띄어쓰기(보조 용언) | 걸어보세요 · 풀어봐요 · 골라보세요 | 걸어 보세요 · 풀어 봐요 · 골라 보세요 |
| 띄어쓰기(의존 명사) | 될까봐 · 혼날까봐 · 최고인가봐 | 될까 봐 · 혼날까 봐 · 최고인가 봐 |
| 합성어 | 국어 낱말게임 | 국어 낱말 게임 |
| 단위 표기 | 12낱말 | 낱말 12개 |

**조사를 받침에 맞게 자동으로 고릅니다.** 이전에는 "짝수은", "민준야", "정답은 사과 예요"처럼 어색한 문장이 나왔습니다. 이제 받침 유무를 보고 `은/는`, `이/가`, `로/으로`, `아/야`, `이에요/예요`를 골라 씁니다. 숫자로 끝날 때는 한글로 읽었을 때의 받침을 따집니다(3 → 삼 → "3이에요", 12 → 십이 → "12예요"). `(으)로`처럼 두 형태를 나란히 적던 표기도 없앴습니다.

**낱말 채점은 띄어쓰기 차이를 무시합니다.** 정답이 `화석연료`로 저장돼 있어도 아이가 사전 표기대로 `화석 연료`라고 쓰면 정답입니다.

챗봇의 `keywords` 배열은 **일부러 고치지 않았습니다.** 아이가 "잘가", "몇개", "로블럭스"처럼 붙여 쓰거나 다르게 적어도 알아듣게 하려고 넣어 둔 매칭용 표기입니다.

- **v1.8**: ① 🔠 **영어 단어 250 → 1,000낱말**, 학년제 **10단계(초1·초3·초4·초6·중1·중2·중3·고1·고2·고3)**로 확장 ② 📖 **영어 문장 문제 신설** — 학년별 빈칸 채우기(1~5단계)·문장 뜻 고르기(6~10단계), 총 200문항 ③ **모든 문제 제한시간 1분** + 화면 카운트다운, 1분 초과 시 오답 처리하고 다음 문제로 ④ 다음 문제로 넘어가기 전 **정답 3초 표시** ※ 10단계 학년제는 영어(단어·문장)에만 적용하고, 수학·국어·구구단은 기존 5단계를 유지합니다
- **v1.7**: ① 끝말잇기 — 아이가 낸 낱말은 **사전에 없어도 끝말만 이어지면 인정**하고 요정이가 뜻을 모른다고 답한 뒤 이어감 ② 사전 1,497 → **10,000낱말**(국립국어원 한국어기초사전 기반 2티어) ③ 요정이가 초등 어휘·짧은 낱말 우선 선택 ④ 사전 인덱스 지연 생성으로 초기 로딩 개선(앱 시작 비용 27ms → 2ms) ⑤ **화면 문구 맞춤법 전면 검수 및 조사 자동 선택** ⑥ 낱말 채점에서 띄어쓰기 차이 허용
- **v1.6**: 🔗 **끝말잇기 게임 추가** — 주제 12개, 초등 수준 낱말 1,497개 내장 사전, 두음법칙 양방향 허용, 중복 검사, 한 턴 60초, 라운드 승리 보너스. 학습 기록 화면은 끝말잇기를 "주제 · N낱말"로 표시하고 평균 정답률 통계에서는 제외
- **v1.5**: 문제은행 확장 — 국어 낱말 250개, 영어 낱말 250개, 문장 빈칸 100개, 상황 판단 150개 등 총 700개 이상으로 증설 (수학·구구단은 자동 생성 유지)
- **v1.4**: "국어 문장 연습" 추가 — 1~2단계 빈칸 채우기, 3~5단계 생활 속 상황 판단 객관식 (실제 AI 채점이 아닌 사전 정의된 정답 매칭 방식)
- **v1.3**: 영어 단어 발음 듣기(🔊) 기능 추가, 요정이 챗봇에 가면라이더·파워레인저·로블록스 잡담 카테고리 추가
- **v1.2**: 규칙 기반 마스코트 챗봇("요정이와 대화하기") 추가
- **v1.1**: 프로필에 사진 첨부/변경 기능 추가 (프로필 목록·홈 화면에 표시)
- **v1.0 (MVP)**: 최초 출시. 국어/영어 단어 뱅크는 난이도별 10개씩(총 50개) 등록

다음 버전에서는 일별 사용시간 통계와 학부모용 요약 리포트(사용시간 초과 시 이메일 알림)를 추가할 예정입니다.
